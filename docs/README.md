# USB-Container
Inspired from (not copied): Credits to af_inventions for the idea:
https://thangs.com/designer/af_inventions/3d-model/USB%20NOTE%20%7C%20STICKY%20BOTE%20HOLDER%20%26%20STENCILS-1546020
I only saw the picture of how it looks, however, the working principle, and modelling was done by me alone.

A 3D printed HUGE USB dongle which can hold your sticky notes, pens, and so much more!
I love having sticky notes and stencils to use for them. However, I can not always keep them stored in 1 lousy box which may or may not get lost on a daily basis. 
This USB container has the ability to hold all you sticky notes in place, along with providing you with 4 different types of stencils, and a pen and pencil holder. It is shaped like a USB drive, but instead of storing software data, it stores TEXT data. PlS TELL ME U GOT THE JOKE!

As seen in the above image, the Sticky notes can be placed within the pin of the container, while the stencils are hidden in the red container which can only be removed by seperating the usb pin from the button container. It is easy to do so, as you can just pull them apart (They are attached by magnets). The container also comes with 4 holes to hold your pen and pencils and a button which is connected to a mechanism which, when pressed launches the sticky notes out of the USB pin.
